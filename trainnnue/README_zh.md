# 当前 NNUE：表示、整数计算与训练

[English](README.md) · [系统报告](../README_zh.md) · [当前评测](../docs/nnue_g006_20261106/REPORT_zh.md) · [机器配方](../docs/nnue_g006_20261106/recipe.json)

本页给出在线g006评价器的完整计算定义。网络以两个视角读取同一张稀疏特征表，分别累加128维向量，经CReLU和一个阶段线性头产生PST残差。训练采用左右将位共享；部署把共享行展开，以int8特征和int16累加器运行。

## 1. 坐标、符号和张量

棋盘为10行9列，行0是黑方底线、行9是红方底线，列0至8对应数组左右。大写棋子属于红方、小写属于黑方。内部搜索、原始标签与PST以红方有利为正。

为使一个网络服务双方，训练和下列公式使用行棋方视角。记 $\sigma=+1$ 表示红走、$\sigma=-1$ 表示黑走，则 $S=\sigma S_{\rm red}$、$P=\sigma P_{\rm red}$。网络输出的正残差表示有利于当前行棋方；内部搜索把残差乘回 $\sigma$ 后加入红方PST。

| 对象 | 尺寸或取值 | 含义 |
|---|---|---|
| $F_v(B)$ | 最多32个特征 | 视角$v$下所有在场棋子的索引 |
| $W$ | 11340×128逻辑特征表 | 其中7560行是独立参数；训练映射取共享行，导出显式展开 |
| $b$ | 128 | 两个视角共用的累加器偏置 |
| $a_{\rm 红},a_{\rm 黑}$ | 各128 | 两个视角的特征和 |
| $h$ | 256 | 按行棋方、对方顺序拼接的激活 |
| $v_p,c_p$ | 256和1 | 阶段$p$的输出权重和偏置 |
| $K$ | 65.38910923790853 | 残差损失的固定归一化尺度 |
| $E,O$ | g006为20、128 | 特征与输出量化倍率 |

PST包括子力基础值和位置奖励。双方将帅也参与网络特征；棋盘总子数含将帅，并用于选择阶段头。

## 2. 从棋子到特征行

视角为红方时坐标保持不变；视角为黑方时，把棋盘坐标旋转为 $(r,c)\mapsto(9-r,8-c)$。这样本方将帅总在底部九宫。设旋转后本方将帅位置为 $(r_k,c_k)$：

$$k=3(r_k-7)+(c_k-3),\quad q=9r+c,\quad f=(14k+2t+u)\,90+q.$$

$k\in\{0,\ldots,8\}$ 为将位桶；$t$ 按兵、炮、马、象、士、车、将编号0至6；$u=0$ 为本方棋子、$u=1$ 为对方棋子；$q$ 是该棋子的格。由此得到11340个可能索引。网络对实际在场棋子的行求和，缺席棋子没有特征。

将位在九宫右列的桶2、5、8，分别映到左列桶0、3、6，并同时把棋子列变为 $8-c$。左列桶和中线桶直接保留，因此训练只需6个将位桶、7560行。中线桶1、4、7中的左右棋子格仍是独立参数。这个映射保留“将位与棋子位置一起镜像”的对应关系，而不会单独把中线将位下的左右布局压到同一行。

训练取行时使用映射；导出逐一遍历完整11340个索引，把对应训练向量复制进去。推理仍按上式直接寻址。另有50%的整局面水平镜像增强，它给中线桶提供对称数据，但没有强制它们共享权重。

## 3. 浮点前向和训练目标

设$s$为行棋方、$o$为对方，$C(x)=\operatorname{clip}(x,0,1)$逐元素作用：

$$a_v=b+\sum_{f\in F_v(B)}W_f,\qquad h=[C(a_s);C(a_o)].$$

总棋子数大于20时$p=0$，否则$p=1$。选择该阶段的线性输出：

$$z=v_p^\top h+c_p,\qquad r_{\rm float}=Kz.$$

两个头各有256个权重和1个偏置。生产推理只计算所选头；训练批量计算两个头，再按每个样本的阶段取值。结构没有额外稠密隐藏层或sigmoid。非线性来自累加后的CReLU；输出头给出连续残差。

教师搜索最佳分与PST先统一到行棋方视角，再构造目标：

$$d_i=\operatorname{clip}(S_i-P_i,-250,250),\qquad L=\frac1N\sum_i\left(\frac{r_i-d_i}{K}\right)^2.$$

$N$ 为批内局面数，$r_i$ 为预测残差。浮点训练取$r_i=Kz_i$，不预先截到±300。QAT阶段取真实整数推理的总分减PST，因而包含实际残差及总分限幅。最终胜负、概率误差和额外辅助损失均不参与本轮目标。K在本轮固定：它规定损失单位，也把归一化网络输出还原成分数；本轮没有用终局结果重新估计K。

计算示例：PST为80、最佳搜索分为140，则目标是60；若网络预测45，单样本损失为 $((45-60)/65.3891)^2\approx0.0526$。这说明网络拟合的是最佳搜索相对PST的修正，而不是直接预测该盘最终输赢。

## 4. 从浮点参数到整数推理

记$R(x)$为四舍五入、半整数远离零。g006使用$E=20$、$O=128$，导出参数为

$$\begin{aligned}
W_q&=\operatorname{clip}(R(EW),-128,127),\\
b_q&=\operatorname{clip}(R(Eb),-32768,32767),\\
v_{q,p}&=\operatorname{clip}(R(KO v_p),-32768,32767),\\
c_{q,p}&=\operatorname{clip}(R(KEO c_p),-2^{31},2^{31}-1).
\end{aligned}$$

K已经折入输出权重和偏置，CPU推理时无须再乘浮点K。实际执行：

$$\begin{aligned}
A_v&=b_q+\sum_{f\in F_v(B)}W_{q,f},\\
H&=[\operatorname{clip}(A_s,0,E);\operatorname{clip}(A_o,0,E)],\\
Z&=c_{q,p}+\sum_{j=1}^{256}v_{q,p,j}H_j,\\
r&=\operatorname{clip}\left(R\!\left(\frac{Z}{EO}\right),-300,300\right),\\
V&=\operatorname{clip}(P+r,-19999,19999).
\end{aligned}$$

例如浮点特征值1.17在E20下舍入为23，对应还原值1.15；特征格点间隔为0.05。最终输出除以2560，是同时还原特征尺度和输出尺度。训练标签±250、推理残差±300、总分±19999分别约束不同对象。

### 选E和防溢出

浮点最佳模型确定后，从实际参数选满足以下条件的最大正整数 $E\le32767$。先取未经夹紧的候选整数 $\widetilde W=R(EW)$、$\widetilde b=R(Eb)$，要求 $\widetilde W$ 位于int8范围，并且对每个维度$j$，

$$|\widetilde b_j|+64\max_f|\widetilde W_{fj}|\le32767.$$

最终棋盘最多32子；将位缓存按格替换旧快照时，中间值可能暂时混合新旧棋盘贡献，所以使用64项边界。CReLU发生在累加之后，不能用于防止此前的累加溢出。

g006浮点特征范围为[-4.855811,6.253492]，E21会使正端越出int8，选得E20。QAT成品整数特征范围为[-98,125]，最大上述累加边界为8007。固定E后继续训练，并在导出和生产加载时检查安全条件。

输出层的激活和权重均为int16。AVX2内核先把相邻两个乘积相加到int32，再沿8条int32通道累积。加载器验证 $E\sum_j|v_{q,p,j}|\le\mathrm{INT32\_MAX}$ 后使用该快速路径，最后转int64加入偏置；未通过时使用int64后备累计。g006两头的点积绝对上界为11,148,860和10,063,220。

磁盘文件沿用v3格式，以int16槽保存特征、int32槽保存特征偏置；这些特征值实际已在int8范围。生产加载后转为真正的int8特征数组，并使用int16累加器。文件大小2,904,632字节与热路径运算位宽是两个不同指标。

### QAT优化什么

QAT保留浮点主参数，前向模拟上述整数舍入、缩放与截断，损失计算看到的是部署分数。反向传播用直通估计器穿过舍入：舍入操作传单位梯度，整数除法按分母缩放梯度，截断保留对应梯度规则。这样参数仍能连续更新，并适应有限格点。

g006同一验证集的归一化残差MSE为：浮点最佳0.491871，直接量化0.497580，QAT后原生整数评分0.488677。这个对照说明QAT改善了该模型的量化拟合；棋力评价另用等实际耗时对局。

## 5. 搜索树中的累加器生命周期

普通走子在将位桶不变的视角下更新

$$A'=A-W_{q,\rm 原格}+W_{q,\rm 新格}-W_{q,\rm 被吃子}.$$

原格和新格都包含同一棋子的类型与敌我通道；被吃子使用自己的通道。无吃子时省去最后一项。

实际实现的顺序如下：

1. `make_move` 更新棋盘、PST、哈希和规则路径，把走法及动子／被吃子压入新惰性帧，先不计算神经向量。
2. `evaluate` 请求某个视角时，若当前帧已计算则直接使用；否则找最近已计算的祖先。
3. 直接父帧已计算时，在一个循环中从父累加器读取，完成减旧、加新、减被吃，并写当前帧。跨多层时重放中间变化，首步把复制与更新融合。
4. 本视角将帅移动使所有行的将位桶变化，此时从该将位的缓存重建；另一视角仍按普通变化更新。
5. `undo_move` 恢复棋盘并退回父帧，父帧累加器保持原值。无需把子帧向量逐项反向修改。

将位缓存为两个视角各九项，每项保存一份90格棋盘快照和对应累加器。重建比较快照与当前棋盘，只对不同格删除旧棋子、加入新棋子，然后更新该缓存快照。普通走子不维护这些快照；缓存可跨搜索分支保留，因为每次使用都按自己的快照计算差异。初始化新局面时清空缓存。

惰性帧减少被剪掉节点的无效向量更新，融合循环减少累加器读写；两者都保留同一评分函数。激活与256维输出点积仍在实际评价时执行。

## 6. 一代训练数据的实际流水线

g006的统一评分教师为g005。教师分别与PST和g001至g005对弈，每来源重新产生200万有效局面；PST对手走子D4，NNUE走子D3，所有来源的标签均由g005以D3给出。首代起点为PST对PST，此时走子和标签均为D4。

每盘先随机合法走6个半回合，这段不采样。之后先按0.5/0.3/0.2抽取根着名次；只有两着按5:3归一，只有一着直接选择。最长120个半回合，开局后每2个半回合采样，并轮换相位和双方执色。

```text
当前局面B：
    先抽取本步需要的名次k
    用统一教师做独立单PV搜索，保存最佳分S
    满足采样相位时记录(B, 行棋方, S, PST, game_id, 来源)
    用当前走子引擎找第一根着；教师执子时可复用上述结果
    若k>=2：排除第一根着后完整窗口搜索第二根着
    若k=3：排除前两根着后完整窗口搜索第三根着
    执行第k根着
```

额外排名搜索禁止写TT，并恢复history、killer、counter和TT age；最佳标签已在探索前保存。没有评分差过滤。教师标签搜索关闭TT分数截断、空步、LMR、LMP、futility、razoring、reverse futility及SEE删选，保留PVS、Alpha-Beta合法截断、将军延伸、静态搜索和循环规则。

数据处理剔除当前被将军或 $|S_{\rm red}|\ge19999$ 的记录，按90格棋盘加行棋方全局去重。无评分冲突的重复项保留一个代表。重复输入出现评分冲突时，若PST一致、存在非零搜索分且所有非零分一致，则保留非零代表；否则丢弃冲突组。g006有19组搜索分冲突，其中10组按此规则保留、9组丢弃。教师保留根前路径，而网络没有路径特征，是这里的实际信息差。

每盘game_id经固定哈希分配到98%训练、1%验证、1%留出；按来源、划分和行棋方配额抽取，再全局打散。g006为11,760,000训练、120,000验证、120,000留出；每来源分别为1,960,000／20,000／20,000，红黑各半。留出集本轮未用于训练、早停、选E或重新标定K。

## 7. 优化、早停与成品选择

每代随机初始化共享特征 $\mathcal N(0,0.01^2)$，累加器偏置和两个输出头全部置零。初始修正为零，浮点训练逐步拟合教师残差。训练设备为GTX1650Ti；AdamW权重衰减为 $10^{-6}$，有效batch8192由四个2048微批累积，梯度范数裁剪1。每轮全局重新洗牌，样本以50%概率水平镜像。

| 参数 | 浮点训练 | 固定E的QAT |
|---|---:|---:|
| 初始学习率 | 0.003 | 0.0003 |
| 最大／最少轮数 | 150／25 | 30／5 |
| patience | 15 | 8 |
| 最小验证改善 | 1e-5 | 1e-7 |
| 随机种子 | 20261032 | 2026110191 |
| 实际完成轮数 | 37 | 9 |
| 选中检查点 | 第22轮 | 第1轮 |

余弦学习率日程以阶段最大轮数为周期参数，下限为初始学习率的3%。按验证残差MSE选择检查点，包含epoch0；满足最少轮数后，连续patience轮没有达到最小改善量便停止。早停可能在日程到达最低学习率前发生。

成品导出后逐值核对整数模拟与C++原生评分，再进行独立实际耗时校准和换色赛。每个已有对手的点得分率必须严格超过50%才能晋级；一项未过仍完成该轮所有预定对手，再停止扩代。当前g006通过六项内部对照，完整得分、计时、区间和模型身份见[当前评测报告](../docs/nnue_g006_20261106/REPORT_zh.md)。
