# 《如何让电脑下中国象棋》展示稿

双击 `index.html` 即可播放。页面复用相邻 `slides/` 中的 Reveal.js 和两张截图，因此请保留两个目录的相对位置。

- `→` / `Space`：下一页
- `←`：上一页
- `F`：全屏
- `S`：打开演讲者视图（含备注）
- `Esc`：总览

全稿 20 页，主线是：棋盘表示 → 走法与合法性 → PST 评估 → Minimax → 搜索优化 → 时间与重复规则 → 程序接口。

评估部分按当前 `xiangqi_ai.cpp` 的真实实现表述：`evaluate()` 返回增量维护的完整 PST 总分；`PIECE_VALUES` 不作为独立的静态评估项。
